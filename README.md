# Video Recorder Android App

오른쪽 위의 **녹화** 버튼을 누르면 후면 카메라와 마이크로 녹화를 시작합니다. 다시 누르면 녹화를 종료하고 갤러리의 `Movies/VideoRecorder` 폴더에 MP4로 저장합니다.

## APK 받기

1. 저장소의 **Actions** 탭을 엽니다.
2. `Build Android APK` 실행이 초록색으로 완료될 때까지 기다립니다.
3. 실행 결과 아래의 **Artifacts**에서 `VideoRecorder-APK`를 다운로드합니다.
4. ZIP 압축을 풀어 `app-debug.apk`를 안드로이드 휴대폰에 설치합니다.

앱은 카메라와 마이크 권한을 요청하며, 녹화 중에는 화면 상단에 REC 표시와 시간이 나타납니다.
